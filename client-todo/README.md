# Client To-Do

A simple to-do list for Motion Media clients. Add a client, list what needs to get done, and check tasks off as you go.

This is a single static page (`index.html`) with no build step. Tasks are saved in the browser you use, so they stay on that device and that browser only. Clearing browser data will erase them.

## Deploying on Vercel

1. Upload this folder to a GitHub repository.
2. In Vercel, choose Add New > Project and import that repository.
3. Leave Framework Preset set to "Other". Leave the build command and output directory empty.
4. Click Deploy.
